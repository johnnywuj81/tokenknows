2. Bug 与解决

Cursor 扩展在 macOS 偶发崩溃（Issue #87）📎 4：根因为扩展在 Apple Silicon 上调用 native module 时未正确处理 ARM64 / x86_64 差异。@dave 提交 PR #138 增加架构检测逻辑，下周一发布修复版本。

幻觉问题修复（生成的 ADR 引用了不存在的 PR）📎 2：在生成 Prompt 中加入 critic 步骤，强制模型在引用前验证 PR 是否存在。@carol 主导，已在 W22 全部新生成文档中应用。

Claude

3. 关键决策

  • 不直接使用 LangChain📎 5：经过 @alice 与团队讨论，决定自研轻量 LLM 抽象层。理由：LangChain 的 chain / agent 抽象过重，与本项目"task → adapter"路由模型不匹配；自研可控、易测、易私有化。
  • 采用 Postgres + pgvector 替代独立向量库📎 3：MVP 规模下事件量 < 10M，pgvector 性能足够；私有化部署少一个依赖组件，运维成本降低。
  • VS Code 扩展推迟到 S6📎 2：Copilot Chat API 授权路径未稳定，需要单独 spike。Claude Code 优先（覆盖 80% 重度用户）。
