迭代 Prompt：要求 Agent 给出三种方案对比。当前 Agent 倾向直接给出一个方案，有时候不够全面。

Assistant

我建议在 system prompt 里加上明确指令：

When proposing a solution, ALWAYS present:
1. The most direct approach
2. An alternative with different tradeoffs
3. An aggressive/experimental option

Conclude with a brief comparison table.

这样可以强制 Agent 在每次回答时都过一遍多方案空间。配合 critic 步骤效果会更好。
